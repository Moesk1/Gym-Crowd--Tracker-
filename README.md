# Gym-Crowd--Tracker-
A app for tracking how crowded the campus gym is
My project is a Gym Crowd Tracker. Basically it’s a web app where students can check in and out of the campus gym, and it’ll show you roughly how crowded it is at that moment not busy, kind of busy, or really busy just based on how many people are currently checked in. The whole point is so you don’t have to walk all the way over there just to find out it’s packed. No sensors or cameras or anything fancy, just people checking themselves in and out.
Stack:
Python — Programming language
Flask — Web framework
SQLite — Database
pytest — Testing
Git/GitHub — Version control
GitHub Copilot — AI coding tool
